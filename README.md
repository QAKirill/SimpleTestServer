# Simple Test Server with Spring Demo

![Java](https://img.shields.io/badge/Java-21-orange)
![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.*-green)
![Gradle](https://img.shields.io/badge/Gradle-8.x-blue)

Демонстрационный проект автотестов с использованием Spring Boot. В комплекте идёт простой встроенный сервер для 
запуска тестов.

### 🛠 Технологический стек:

* **Язык и сборка:** Java 21, Gradle
* **Фреймворк:** Spring Boot 3.*
    * *Web:* Spring MVC
    * *Persistence:* Spring Data JPA
* **База данных:** H2
* **Тестирование:**
    * JUnit 5
    * REST Assured
    * AssertJ
